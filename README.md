# LungCancer-miRNA

## Overview
This project presents a comprehensive benchmarking framework for lung cancer classification using miRNA expression profiles and Machine Learning algorithms.

The study evaluates 35 computational approaches to identify the most accurate predictive model and discover biologically relevant miRNA biomarkers associated with lung cancer.

---

## Objectives

- Benchmark 35 Machine Learning algorithms
- Classify Lung Cancer using miRNA expression data
- Identify important miRNA biomarkers
- Compare model performance using multiple evaluation metrics
- Improve interpretability through biomarker analysis

---

## Dataset

- Samples: 732
- Features: 1881 miRNA expression profiles
- Classification: Binary (Normal / Lung Cancer)

---

## Methods

- Data Preprocessing
- Standardization (StandardScaler)
- ANOVA Feature Selection
- Feature Importance Analysis
- Cross Validation
- Hyperparameter Optimization
- Model Benchmarking

---

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

---

## Best Result

The Apriori-based model achieved the highest overall performance among all evaluated methods.

Top selected biomarkers include:

- hsa-miR-126
- hsa-miR-210
- hsa-miR-139
- hsa-miR-451b
- hsa-miR-135b
